# 构建与安装

## 环境要求

| 组件 | 版本 | 说明 |
|---|---|---|
| JDK | 17 | 必须 17，AGP 9 不支持 8 和 11 |
| Gradle | 9.3.1 | 由 wrapper 自动下载，无需预装 |
| Android Gradle Plugin | 9.1.0 | 在根 `build.gradle.kts` 声明 |
| Android SDK Platform | 36 | `compileSdk = 36` |
| Build Tools | 36.0.0 | |

## SDK 路径

`local.properties` 指定本机 SDK 位置（此文件已在 `.gitignore` 中，不进仓库）：

```properties
sdk.dir=/opt/homebrew/share/android-commandlinetools
```

克隆后需要自己创建这个文件，或直接用 Android Studio 打开工程自动生成。

## 构建命令

```bash
cd ChargeScope
JAVA_HOME=/Library/Java/JavaVirtualMachines/temurin-17.jdk/Contents/Home \
  ./gradlew assembleRelease
```

产物：`app/build/outputs/apk/release/app-release.apk`，约 2.0 MB。

调试版：

```bash
./gradlew assembleDebug
# app/build/outputs/apk/debug/app-debug.apk
```

## 安装到手机

```bash
adb install -r app/build/outputs/apk/release/app-release.apk
```

或者把 APK 传到手机（微信、QQ、数据线均可），点击安装，首次需允许「安装未知来源应用」。

## 坑一：AGP 9 内置 Kotlin，不能再用独立 Kotlin 插件

如果你照旧写：

```kotlin
plugins {
    id("org.jetbrains.kotlin.android") version "2.4.0"
}
```

构建会失败，AGP 9 已经内置 Kotlin 支持，两者冲突。本项目根 `build.gradle.kts` 只有一行：

```kotlin
plugins {
    id("com.android.application") version "9.1.0" apply false
}
```

模块里也只声明 `com.android.application`，不声明任何 Kotlin 插件。

## 坑二：依赖下载慢

首次构建要拉 AGP、Kotlin 编译器、AndroidX 等，从 `dl.google.com` 和 Maven Central 直连可能只有几十 KB/s，表现为**卡住不动**（不是报错）。

解决办法是在 `~/.gradle/gradle.properties`（全局，不是项目内）里配代理：

```properties
systemProp.http.proxyHost=127.0.0.1
systemProp.http.proxyPort=7897
systemProp.https.proxyHost=127.0.0.1
systemProp.https.proxyPort=7897
```

端口按自己代理软件改。配好后同一台机器上构建从 8 分钟降到 26 秒。

依赖缓全之后可以离线构建：

```bash
./gradlew assembleRelease --offline
```

## 关于签名

`app/build.gradle.kts` 里 release 用的是 debug 签名：

```kotlin
buildTypes {
    release {
        isMinifyEnabled = false
        signingConfig = signingConfigs.getByName("debug")
    }
}
```

这意味着：

- APK 可以直接安装，无需额外配置
- **不能上架应用商店**，也不能作为正式分发给他人
- 换一台机器重新构建，签名不同，覆盖安装会失败（需先卸载）

要正式发布，需生成自己的 keystore 并替换 `signingConfig`。

## 版本配置

```kotlin
compileSdk = 36
minSdk = 29        // Android 10
targetSdk = 34     // Android 14
```

`minSdk = 29` 是 `BatteryManager.getIntProperty` 稳定可用的下限。`targetSdk = 34` 是为了避免 Android 15+ 的前台服务与通知新规带来额外适配——本项目没有前台服务，用不上更高版本的能力。
